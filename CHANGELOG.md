# JanSeva AI Changelog

All notable changes and version milestones for **JanSeva AI** are documented here.

## [1.0.0] - 2026-09-01

### Added
- **AI Scheme Recommendation Engine**: Match percentage evaluation score (`88% Match`) based on citizen demographic criteria.
- **RAG JanSeva Assistant**: RAG-powered chatbot with scheme knowledge retrieval and official reference citations.
- **Interactive Eligibility Wizard**: 6-step guided criteria evaluator.
- **DBT Scheme Application System**: Digital application submission with Multer supporting document dropzone upload (PDF, JPG, PNG).
- **Officer Verification Queue**: Split-view document verification inspector with decision approval/rejection notes.
- **Admin Governance Dashboard**: System analytics charts powered by Recharts and complete scheme CRUD editor.
- **Service Center Locator**: React Leaflet & OpenStreetMap interactive map locator.
- **Public Grievance Redressal**: Ticket submission, status tracking, and officer response thread.
