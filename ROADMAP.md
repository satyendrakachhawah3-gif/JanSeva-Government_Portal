# JanSeva AI - Product Roadmap & Future Milestones

## Vision
To deliver a seamless, zero-friction digital doorway for over 1 billion citizens to discover, verify, and receive benefits under Indian Union & State government welfare schemes.

---

## Roadmap Phases

### Phase 1: Core Platform & AI Recommendation (Completed Q3 2026)
- [x] Full MERN stack infrastructure with JWT Auth & RBAC controls.
- [x] RAG TF-IDF NLP scheme eligibility matcher algorithm.
- [x] JanSeva Assistant voice & text chatbot in Hindi and English.
- [x] Interactive Leaflet GIS map locator for nearest Seva Kendras.
- [x] QR code receipt generation & status tracking dashboard.

### Phase 2: Offline & Multi-Channel Expansion (Q4 2026)
- [ ] Progressive Web App (PWA) offline application draft saving.
- [ ] WhatsApp & SMS Bot integration for status tracking without internet.
- [ ] Multi-lingual support expansion to 12 regional Indian languages (Tamil, Telugu, Bengali, Marathi, etc.).

### Phase 3: Verification & Integration (Q1 2027)
- [ ] DigiLocker API integration for automated document verification.
- [ ] Direct Benefit Transfer (DBT) payment status gateway mock sync.
- [ ] OCR Document Scanner for automatic Aadhaar & Income Certificate extraction.
